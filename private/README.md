# Private Research Data

Store identifiable family research, scans, transcripts, downloads, working notes, and exports here. This directory is excluded from Git by the root `.gitignore`.

Suggested folders: `people/`, `sources/`, `questions/`, `research-logs/`, `findings/`, `attachments/`, and `exports/`.

Do not treat Git ignore as a security boundary. Review encryption, cloud sync, backups, device access, and any external service before placing sensitive files here. Review every file before sharing an export.
