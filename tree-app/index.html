        Kinship Atlas help

        Getting started

        Kinship Atlas shows a family tree from a GEDCOM file as an interactive relationship map, with each person's life events, places and media. Everything happens on this device: your file is read locally and is not uploaded.

        First steps

        1. Open a tree. On the welcome page, choose Open GEDCOM and pick a .ged file exported from your family tree program. To start from scratch, choose Create new GEDCOM and enter the first person.
        2. Link your media (optional). After a tree opens you are asked for a media folder so photos and documents referenced in the GEDCOM can be shown. You can skip this and do it later from Settings > Select Media Folder.
        3. Choose a person. Use the directory on the left, or press / to jump to the Find a person search box.
        4. Explore. Click any card in the relationship map to recentre on that person. Their record appears on the right.
        5. Make it yours. Use Set as primary person in a record to add a Home Person button, and Settings > Update defaults to open your tree automatically next time.

        Finding your way around

        • Top bar: Map View, Reports and Media switch views. The name of the open GEDCOM file is shown in the middle; click it to change your defaults. The Saved / Save to GEDCOM indicator shows whether your edits are in the file.
        • Left: the directory of everyone in the tree, with search and filters.
        • Centre: the relationship map for the selected person.
        • Right: the person record, with actions for editing, printing and media.

        Privacy

        Nothing leaves this device unless you choose a feature that says so and tick its consent box: Search WikiTree (in a person record) and Suggest countries with GeoNames (in the birth country list). Each one shows exactly what it will send first.

        Opening & importing GEDCOM files

        A GEDCOM (.ged) file is the standard text format that family tree programs, such as RootsMagic, use to export a tree. Kinship Atlas opens files up to 100 MB.

        Open a GEDCOM

        1. Choose Open GEDCOM on the welcome page or in the Settings menu.
        2. Select the file. The directory fills with everyone in the tree and the first person is shown.
        3. When asked, link a media folder, or cancel and do it later.

        In browsers with local file access (such as Edge or Chrome), the app keeps permission to write back to the file you opened, so your edits can be saved into it. Otherwise, saving asks where to save, or downloads a copy.

        Open a different tree

        Open GEDCOM is removed from the menu while a tree is open. Choose Settings > Start Again to close the current tree, then open the other file. Start Again does not delete any GEDCOM or media files, but any changes that are not yet saved are discarded, so check that the top bar says Saved first.

        Create a new GEDCOM

        On the welcome page, choose Create new GEDCOM, enter a file name and the first person (birth details are optional), then choose Create. The new tree opens straight away.

        Import new people from another GEDCOM

        Use this to add relatives from someone else's export, or from another program, without starting again.

        1. With your tree open, choose Settings > Import new GEDCOM records and select the other file.
        2. Nothing changes yet. A preview shows how many people in the file are:
          • new and related to this tree: these will be added;
          • already in this tree: same first name, last name and birth date;
          • already in this tree, with extra details that can be merged: see below;
          • new but not related to this tree: not imported;
          • without a birth date: not imported, because they cannot be matched.
        3. Check the People to add list, then choose Import … & save, or Cancel to leave your tree untouched.

        Imported people keep their life events and their relationships to each other and to the matching people in your tree. The additions are then saved to your GEDCOM file.

        Merge extra details into matching people (optional)

        If someone in the file matches a person in your tree but the file has more about them, such as extra life events, a birth place, sources, notes or media, the preview lists them under Merge extra details into matching people. Each entry shows the person in the file, the person in your tree it matches, and how many additional records would be added (life events and other details).

        1. Choose Show what will be added on an entry to see each record. Any value that is different in the file, such as another death date, is listed as kept from your tree.
        2. Tick each person to merge, or tick Select all. Nobody is ticked to start with, and unticked people are not changed.
        3. Choose … merge … & save. If the file only has extra details, and nobody new, the button reads Merge … & save.

        Merging only adds what your tree is missing. It never changes or removes anything already in your tree; where the file differs, your tree's value is kept. Family links in the file are not merged this way. Life events, sources and media that already exist in your tree are recognised and are not added twice.

        How people are matched

        • A person in the import file counts as already in your tree when their first name, last name and birth date exactly match someone in it.
        • A new person is only imported if they are linked, directly or through other new people, to someone who matches exactly one person in your tree. If two people in your tree share a name and birth date, neither can be used as a link point, and extra details cannot be merged into them.
        • If nobody new is related and there is nothing to merge, the preview says No related people found or Nothing new to import, and nothing is changed.

        A name-and-date match is not proof that two records are the same person. Review newly imported people, merged details and their links against your sources.

        Exploring the family tree

        The directory

        • Type in Find a person (shortcut /) to search by name.
        • Narrow the list with Birth country, Death country and Occupation Type, and the Birth year and Death year sliders. The filters combine with each other and with the search.
        • People are grouped by surname. Expand or collapse a surname to browse it, or tick Show only next to it to list just that family.

        The relationship map

        • The selected person is shown with their partners, and above and below them are their recorded ancestors and descendants. Click any card to recentre the map on that person.
        • Show siblings (on by default) adds the selected person's recorded siblings beside them.
        • Use ← and → to step back and forward through the people you have viewed, − and + to zoom, and the printer button to print the map on A4.
        • Home Person in the top bar returns to your primary person from any view.

        The person record

        The panel on the right lists the person's recorded life events, relationships, source references and attached media. Click a relative's name to move to them. The map and record show what the GEDCOM says; they do not independently verify it.

        Editing people & saving

        The buttons at the top of a person record let you change the tree:

        • Edit person details: name, sex, and birth and death dates and places.
        • Add Life Event: record another event, such as a residence, marriage, occupation, military service, burial or an event of your own.
        • Add relative: create a new person linked as a parent, child, sibling or partner. You are asked to confirm if the name matches someone already in the tree.
        • ✎ next to a relative: edit the relationship (for example, parent role or marriage details) or delete it.
        • Set as primary person: adds the Home Person button and shows how others are related to this person.
        • Print record: prints the record on A4, without attached media.
        • Search WikiTree: shown for people with a recorded death. It sends the details listed in the dialog to WikiTree only after you tick the consent box.
        • Delete person: removes the person and all links to them from the GEDCOM.

        Dates

        Type dates in GEDCOM style, for example 12 MAR 1883 or ABT 1883, or use the calendar for an exact date.

        Saving

        • Edits are written back to your GEDCOM file automatically whenever the browser allows it. Records and tags you did not edit are preserved.
        • If the browser needs your permission, or a place to save, the top bar shows Save to GEDCOM. Click it to finish saving. It changes to Saved when the file is up to date.
        • Unsaved changes are kept in this browser tab, and you are warned before closing a tab that has them.
        • When Kinship Atlas.exe saves the GEDCOM in its Primary GEDCOM folder, the previous version is kept in Primary GEDCOM\Backups.

        Photos, documents & media

        Link a media folder

        1. Choose Settings > Select Media Folder (shown as Change media folder once one is linked).
        2. Choose Link existing folder, or Create new media folder to make one named after your GEDCOM.
        3. When the browser asks to let the site edit files, choose Allow. This is needed to add files to the folder, and the app only uses the folder you pick.

        Files referenced in the GEDCOM are matched to files in the folder, and a person's primary image appears on their card.

        Add or remove media for a person

        • In a person record, choose Add photo or PDF. The files are copied into the media folder (renamed if a file with the same name exists) and appear under Attached media.
        • The trash icon on a media item unlinks it from that person. The file itself stays in the folder.

        The media library

        Choose Media in the top bar, or Settings > Media library, to review every file referenced in the tree. Search by filename or person, filter by type, preview files, classify them, see who they are linked to, and choose card images. Files that are missing from the folder are listed but cannot be previewed until they are found. Deleting a file here removes it permanently, along with its GEDCOM links.

        Map View, Reports & data checks

        Map View

        Map View plots people on a world map using the places recorded in the tree. Click a pin to open that person. Choose Relationship View to return to the map of relationships.

        Reports

        Reports summarises the tree, including the most popular occupations, media coverage, and how many people have a birth or death country recorded. The death country count only includes people with a dated death, so people who may still be living are left out. Use the printer button to print the reports on A4.

        Occupation categories are worked out from the wording in the GEDCOM, which is left unchanged. Hover over a bar to see how each description was grouped.

        People without a birth country

        1. Choose Settings > People without a birth country to list everyone whose birth place is blank or has no recognised country.
        2. Type a corrected birth place for one or more people. Each row previews the detected country as you type.
        3. Choose Save changes. The places are written to the GEDCOM and the list refreshes to show who still needs a country.

        Suggest countries with GeoNames can look up existing birth places and offer countries to add with one click. It needs a free GeoNames account and your consent each time, and it sends only the place text. GeoNames uses modern country names, so check historical places before accepting.

        Defaults & home person

        Open your tree automatically

        1. Choose Settings > Update defaults, or click the GEDCOM file name in the top bar.
        2. Choose the GEDCOM file and, optionally, the media folder to open at start-up.
        3. Choose Save default. The choice is stored in kinship-defaults.json next to the app, and the browser remembers access to the file and folder.

        This needs a browser with local file access, such as Edge or Chrome. Clear default stops opening a tree automatically.

        Primary person and home person

        • Primary person (Set as primary person in a record) adds the Home Person button to the top bar and shows how others are related to that person.
        • Home person (☆ Set as home person, shown when your default GEDCOM is open) is the person selected when the default tree opens.
        • When a primary person is set, the welcome page offers Go to Home/Default Person in Tree.

        Finishing a session

        Settings > Exit Kinship Atlas saves your preferences and stops the local helper. If there are unsaved GEDCOM changes, you are asked before exiting.

        Updating the application

        Settings > Check for application updates checks published stable GitHub releases without writing local files. Download the Windows setup executable, its Sigstore bundle and SHA256SUMS from the release page. Follow the verification instructions in the README, save your GEDCOM and exit the app and helper, then run setup and select the folder containing index.html. Setup replaces only packaged application files, including the launcher; it does not delete files or include your GEDCOM, media or preferences. Keep personal media outside application asset folders such as flags and data. Sigstore is not Windows Authenticode signing and does not guarantee antivirus acceptance.

        Application update available

        Download and verify the installer, checksum and Sigstore bundle from GitHub. Save your GEDCOM and exit the app before running setup. Select the application folder containing index.html. Sigstore is not a Windows-trusted signature.
